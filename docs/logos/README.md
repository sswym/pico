# srcode — 机器宠物 Logo 设计方案

> 4 个机器人宠物吉祥物角色，Claude Code 紫色/橙色色调，暖深色背景

|角色|昵称|动物原型|SVG 文件|
|---|---|---|---|
|Robo-Cat|**Snippet**|猫|`pet-01-snippet.svg`|
|Robo-Dog|**Source**|狗|`pet-02-source.svg`|

|Terminal Pet|**CLI**|终端提示符化身|`pet-04-cli.svg`|

---

## 方案 1：Snippet — 机器猫

**原型：** 猫 + 代码编辑器

**设计元素：**
- 三角形猫耳（暖橙色）
- 终端光标矩形眼睛（紫色发光）
- 天线 + 信号弧线（接收"指令"）
- 花括号 `{ }` 卷尾
- 胡须 = 三条代码路径
- 嘴巴 `< />` 代码标签
- 身上面板显示代码行

**性格：** 好奇、优雅、时刻关注终端

---

## 方案 2：Source — 机器狗

**原型：** 狗 + 源代码

**设计元素：**
- 垂耳 = 方括号形状 `[ ]`
- 护目镜式屏幕脸（显示光标眼睛）
- 胸口 `<3` 心形代码（表示"热爱编码"）
- 尾巴 = 螺旋弹簧花括号
- 舌头伸出 `$` 提示符
- 爪子 = 命令按钮

**性格：** 友好、忠诚、随时准备执行命令

---

## 方案 3：Byte — 像素宠物

**原型：** 经典 Game Boy / 像素生物

**设计元素：**
- 大圆头 + 单只大眼睛（终端光标形状）
- 身体 = 手持游戏机（带屏幕、D-pad、按钮）
- 屏幕显示心跳曲线（"活力编码"）
- 小圆耳朵 = 暖橙色按钮
- 微笑 = 代码弧线

**性格：** 可爱、怀旧、像素灵魂

---

## 方案 4：CLI — 终端宠物

**原型：** 终端窗口 + 提示符化身

**设计元素：**
- 头部 = 终端提示符 `>_` 的六边形形状
- 眼睛 = `>` `<` 符号（动漫风格的代码表情）
- 身体 = 终端窗口（带红绿灯按钮 + 命令行内容）
- 光标闪烁（实际有 CSS 动画）
- 手臂 = `[` `]` 括号
- 嘴上 `_` 下划线微笑

**性格：** 极客、元气、它就是终端本身
